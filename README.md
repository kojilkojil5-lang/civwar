# 문명전쟁 : 키우기

석기시대부터 미래 문명까지 — 장비를 만들고 시대를 진화시키는 방치형 전쟁 RPG.

## 파일
| 파일 | 역할 |
|---|---|
| index.html | 게임 본체 |
| version.json | 최신 버전 번호 (업데이트 알림용) |
| manifest.webmanifest | 홈 화면 추가(앱처럼 실행) 설정 |
| icon-192.png / icon-512.png | 앱 아이콘 |
| og.png | 카톡·SNS 링크 미리보기 이미지 |

## 업데이트 방법
새 index.html 과 version.json 을 **한 번에 같이** 업로드(커밋)하면
기존 플레이어 화면 위쪽에 "새 버전이 나왔어요" 알림이 뜹니다.
